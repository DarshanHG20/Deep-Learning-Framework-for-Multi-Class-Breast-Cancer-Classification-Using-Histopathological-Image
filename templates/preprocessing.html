Preprocessing Techniques

Resize images to a consistent input size

Why Preprocessing?

Histopathology images may have different dimensions, pixel distributions and visual variations.

Preprocessing provides a consistent representation of the images before they are supplied to the classification model.

Objective: Improve consistency and help the deep learning model learn meaningful visual patterns.
